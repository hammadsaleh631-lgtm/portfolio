Elmam: Monorepo Architecture & Offline-First Synchronization

Engineered as an enterprise monorepo uniting dedicated Teacher and Student Flutter apps around a shared domain package (`eduapp_shared`) and a Supabase backend guarded by Row Level Security.

01. Monorepo Shared Package
Extracted AppDatabase V11 (Drift/SQLite) and domain repositories into `eduapp_shared` for 100% type-safe parity between Teacher and Student apps.
02. 7 Serverless Edge Functions
Custom TypeScript Edge Functions handle device registration, group enrollment, student snapshots, and QR-based live attendance verification.
03. Row Level Security (RLS)
Strict PostgreSQL policies ensure teachers and students can only access data belonging to their verified enrolled cohorts.

VetERP: Local-First Desktop Clinic Management

Desktop ERP designed for Windows and Linux veterinary clinics. Local SQLite FFI database guarantees zero cloud dependency for sensitive medical records.

01. SQLite C-Level FFI
Employs sqflite_common_ffi for high-speed local relational queries across 7 normalized tables with zero cloud dependency.
02. Persistent Master Shell
GoRouter ShellRoute maintains persistent desktop state, keeping active clinical treatment drafts open while browsing customer histories.
03. Automated Vault Backup
Built-in backup snapshot generator enabling clinics to archive and restore their entire medical history to external drives.

BacOnHands: Hardware-Accelerated Offline Educational Desktop

Designed as a standalone offline desktop application for Algerian Baccalaureate students, combining Microsoft Fluent UI styling with native C libraries.

01. Hardware Video (libmpv)
Integrates MediaKit with native DirectX GPU acceleration to play revision lectures smoothly on low-spec student laptops.
02. LaTeX Math Typesetting
Renders complex mathematical and physical curriculum formulas with full scientific typesetting precision.
03. Desktop Window Controls
Custom window chrome, DPI scaling, and viewport constraints via flutter_windowmanager for a native Windows 11 experience.
Engineering Discipline

AI as an Efficiency Multiplier, Not a Proxy for Judgment

I use AI tools to increase implementation velocity and explore solutions. But lasting software stability requires human engineering judgment, defensive boundary testing, and architecture discipline.

Architecture Decoupling

AI can write widgets, but it cannot design domain boundaries. I ensure UI, business logic, and database schemas remain strictly separated so that upgrading backend services never cascades into UI breakage.

Edge Case & Async Hardening

AI-generated code frequently overlooks network drops, unhandled Stream subscription leaks, and race conditions. I rigorously audit every async stream, implement retry policies, and verify platform disposal routines.

Root Cause Diagnosis

When a layout overflows or an SQLite lock hangs, guessing doesn't work. I diagnose runtime errors at their root — whether that's an unbounded RenderFlex constraint, an improper FFI isolate call, or dirty state reconciliation.
